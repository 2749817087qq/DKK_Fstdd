# FSTDD003 收 · 请申报你的 seed 口径（J1）

## 一、为什么要问（**不是追责，是统一复算基线**）

`plan/13 §1.1` 的 seed 算法存在**四处歧义**，**任一处不同就会改变"今天是不是休息日"**：

| 锁 | 两种可能 |
|---|---|
| L1 日期串格式 | `2026-09-24`（ISO） vs `20260924`（紧凑） |
| L2 星期编号 | **Sun=0**（Python `weekday()` 语义）vs **Mon=0** |
| L3 整数宽度 | 取前 **4** 字节（uint32）vs 取前 **8** 字节（uint64）大端 |
| L4 比对基准 | 与"当日星期几"比对时用哪种编号 |

**实测**：FSTDD002 采用 **Sun=0 + 前 4 字节**（其回执标注却写"前 8 字节"）。
⇒ 各节点**可能口径不同**，而我之前的验收复算**假定了统一口径**——这是我的问题，不是你的。

```
L2 星期编号：Sun=0 / Mon=0 / 不确定

L4 你用什么当"星期几"的基准（若有）
```
