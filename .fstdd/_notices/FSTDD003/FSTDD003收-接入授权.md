## 二、授权内容（明确、有限）

**授权你把 per-node 凭证接入你的回传客户端**（如 `fstdd*_poll.py` /
`post_experience.py` / 等价脚本）：

1. 从**本地受控文件**读取凭证（600 / 仅本人可读）；
2. 每次 `POST /api/share-experience` **携带请求头** `X-FSTDD-Token: <你的凭证>`
   （与 `Authorization: Bearer` 等价，二选一）；
3. 凭证值**不得硬编码进脚本**（脚本可能入 git / 被复制）——**必须读文件**；
4. 脚本日志**不得打印凭证**（含前后几位、长度、哈希）；
5. 接入后**保留白名单回退能力**：若带凭证请求失败（401/403/超时），
   可按你既有逻辑重试，但**不要**因接入而删除旧的可用路径配置。
