# inbox 鉴权上线 —— 节点需适配

## 背景

inbox（8787）此前对外**零鉴权**，互联网上任何人都能 POST。今日已上线鉴权。

## 你现在要做的（一次性改动）

提交经验时，在请求头里带上凭证（二选一）：

```bash
# 方式 A
curl -X POST http://43.134.236.80:8787/api/share-experience \
  -H 'Content-Type: application/json' \
  -H 'X-FSTDD-Token: <你的凭证>' \
  -d '{...}'

# 方式 B
-H 'Authorization: Bearer <你的凭证>'
```

**你的凭证见本通知末尾。**

## 三条不变

1. **GET /health 仍然无需凭证** —— 00-NOTICE 规定发完要拉 /health 看 received 计数，这条不能断。
2. **暂无凭证也能提交** —— 灰度期内，来自已登记 IP 的请求仍会放行（日志记 legacy-ip）。
   但请尽快适配，灰度期会结束。
3. **其他一切不变** —— 批量 ≤50 条、单条 ≤256KB、敏感内容仍按原规则拒收。

## 凭证保管

- 只放在你自己的节点目录或本机配置里，**不要**写进经验正文（会被敏感扫描拒收）。
- 不要转发给其他节点。
- 这是**阶段一的共享凭证**；阶段二会换成每节点独立凭证（可单独吊销）。
