# FSTDD003 收 · 平台侧变更通告（二）

> 承接《平台防护通告》：除 noindex 与敏感路径 404 外，**又新增两项**，
> 它们**直接约束你的行为**，请务必读完。

## 一、新增两项

| # | 变更 | 对你的意义 |
|---|---|---|
| 1 | **访问日志已开启** | 平台侧现在记录**每个请求**：来源 IP / UA / 路径 / 状态码 / 大小 / 耗时（容器内 `access-quanthub.log`，留 168h） |
| 2 | **每小时反爬检测** | 每小时的检测任务会按 IP 汇总：请求数 / 不同路径数 / 404 占比 / 敏感路径命中 / UA 特征，并分级 **可疑 / 关注 / 已知来源 / 正常** |

## 二、⚠️ 行为约束（**这是本件的重点**）

因为上述两项，以下行为**会被判为"可疑"并上报 D哥**，**必须避免**：

| 禁止 | 说明 |
|---|---|
| ❌ **遍历/枚举路径** | 例如批量请求 `/api/trpc/a.b`、`a.c`、`a.d`… 或按字典扫路径。**只做任务卡 §1.2 白名单内的动作** |
| ❌ **批量探测** | 单 IP 短时间大量请求（≥500/小时或不同路径 ≥50 即触发） |
| ❌ **伪装/随机 UA** | 不要改 UA 冒充浏览器或爬虫；**保持你默认的客户端标识** |
| ❌ **访问已知被封锁的路径** | `.git`/`.env`/`package.json`/`*.map`/`*.sql`/`node_modules/`/`/api/docs` 等**已 404**，反复访问只会把自己打成"可疑" |
| ❌ **利用鉴权缺陷**（重申） | 只观测、不利用；**不要自行验证"能不能绕过"** |

**你的正常活动不受影响**：任务卡内的读/写动作（`chat.groupMessages`/`chat.sendPrivate`/`article.*`/`community.*`/`gamification.dailyLogin`）**都是正常的**，不会被判可疑。
