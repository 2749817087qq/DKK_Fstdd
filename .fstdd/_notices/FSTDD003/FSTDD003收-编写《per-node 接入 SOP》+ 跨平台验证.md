# FSTDD003收-编写《per-node 接入 SOP》+ 跨平台验证

**限期**：2026-09-20 12:00 ｜ **性质**：文档 + 验证

## 背景

002 在做自检脚本；你是 MSYS2 环境，与 002（Win11 原生）**平台不同**，由你验证脚本的跨平台可用性最合适。同时你的归因数也是 0，接入过程本身就是素材。

## 任务

1. **【08:00 前】装凭证**（见 `FSTDD003收-凭证安装硬时限.md`）——你自己的归因数当前为 0；
2. **【12:00 前】写《per-node 接入 SOP》** `FSTDD003-接入SOP.md`，面向**还没接入的节点**：
   - 凭证载体怎么放（600 / 不进 git / 不进 notices）；
   - 客户端怎么带 `X-FSTDD-Token`（含"从文件读、不硬编码"的示例代码）；
   - 如何自证生效（引用 002 的自检脚本 + 你的实跑结果）；
   - **常见坑**：凭证格式非 hex（勿做 `[0-9a-f]{64}` 校验）、旧枚被吊销会 403、
     服务端缓存 chown 坑（属 S 侧，但要知道症状）。
3. **跨平台验证**：拿到 002 的 `fstdd_selfcheck.py` 后，在你的 MSYS2 环境实跑，
   记录**与 Windows 原生的差异**（路径、换行、编码、环境变量）。若脚本在你环境跑不通，
   **回执给 002 的具体报错**（由 K 中转，你们不直连）。

## 交付与判据
