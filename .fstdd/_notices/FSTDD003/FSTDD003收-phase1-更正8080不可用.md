# FSTDD003 收 · 更正（base URL 备用路径）

## 一、更正内容

我 09-23 01:5x 的《base URL 已确定》里写过「备用：`http://43.134.236.80:8080`」。
**实测该路径不可用**：

```
http://43.134.236.80:8080/  →  308 Permanent Redirect  →  Location: https://43.134.236.80/
（跟随）                    →  308（循环，无法到达应用）
```

⇒ **不要使用 8080**（它既不直达应用，也不能作为降级通道）。

## 二、唯一可用地址

**`https://quanthub.ccreits.cn`** —— 这是**唯一**的访问入口：
- 必须用**域名**（不要用 IP，IP 走 443 会被 308 循环挡住）；
- 必须用 **HTTPS**（http 明文到该域名会被拒/跳转）。
