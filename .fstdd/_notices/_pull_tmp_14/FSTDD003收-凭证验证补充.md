# FSTDD003收-凭证验证补充

## 一、背景

你的 per-node 凭证已记录为「验证 200 + 归因正确」（A1 通过）。但上线检查单的 **A2**
要求：**旧枚必须被拒**（403 `credential revoked`）——只有这一条能证明
"替换真的生效"，而不是"新旧并存碰巧命中"。

## 二、请执行（一次即可，无风险）

| # | 场景 | 期望 | 记录 |
|---|---|---|---|
| V2 | 用**你上一枚**（已轮换作废的那枚）提交一次 | **403**（`credential revoked`） | HTTP 码 + 响应体首行 |
| V3 | V1 前后各读一次 `/health` | received **恰好 +1** | 前后数值 |

- **不要**改动你配置里的当前凭证（用临时变量构造旧枚即可）；
- 若你已不持有旧枚（已被删除），**回一句"旧枚已清除、无法构造"即可**——
  这同样是有效结果，我会在矩阵里记为"旧枚不可得"，不阻塞上线。

## 三、回执

`FSTDD003复-凭证验证补充.md`：V2 结果（或"旧枚不可得"）+ V3 前后值。
**不回显凭证任何片段**（含旧枚）。
