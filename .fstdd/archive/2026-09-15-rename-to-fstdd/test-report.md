## 六、已知问题与未完成项

### 1. 归档文档保留旧标识（预期，非缺陷）

`.fstdd/archive/**/*.md` 内含 `stdd-*`、`/stdd-upgrade` 等旧名。
**刻意不改** —— 它们是当时的真实记录，修改会破坏历史可追溯性。

### 2. `experiences/` 导出目录含旧名引用（低）

经验导出产物中引用了旧标识。属快照性质，下次导出即自然更新。

### 3. macOS 未实测（低）

Windows 与 Linux 均已实测通过（Linux 见 2026-09-15 记录）。
macOS 同属 POSIX，风险低，但**没有环境就不能声称验证过**。

### 4. 远端仓库未改名（中，需 D哥 决策）

本地已全部改为 Fstdd，但 GitHub 上的仓库仍叫 `DKKstdd`。
远端改名属**外部动作**，且会改变 URL，需所有者确认后执行。

### 5. 经验回传链路未复验（中）

`share_experience.py` 的目标仓库名已改为 `Fstdd-experiences`，
但该远端仓库**尚不存在**。在仓库改名/新建前，回传链路处于中断状态。
