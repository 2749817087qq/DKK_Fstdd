## 现象

`fstdd init` 初始化时输出：

```
  [STDD] 拉取社区经验库...
  Pulling experience pack: python (version: v1.0.0) ...
  [FALLBACK] github unreachable (404 Client Error: Not Found for url:
    https://github.com/leonai42/stdd-experiences/releases/latest/download/experience-python-latest.tar.gz)
    switching to gitee mirror
  Error: all registries unreachable
```

但 init 仍成功完成（骨架生成、CONSTITUTION 生成、agent_tests 创建均正常），
仅自检显示「经验库: ⚠️ 空」。

## 根因

`leonai42/stdd-experiences` 仓库未发布对应 release asset（404 Not Found），
gitee 镜像同样不可达。属上游社区资源问题，非本机配置错误。

## 修复

**无需修复**——经验库为空不影响主流程。可选手动重试：

```bash
<venv_python> <upstream>/bin/fstdd experience pull
```

本机自建经验（`.fstdd/experiences/EXP-*.md`）仍可正常沉淀与回传。
README 故障排除表已列明此条为非致命。
