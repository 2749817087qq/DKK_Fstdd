## 现象

归档"本机运行产生的 skill"时，无法仅靠目录名区分运行产生 vs 平台/市场产生。

## 复现

对全局 skills 目录逐目录扫描：

1. 读 SKILL.md frontmatter 的 agent_created 字段
2. 查是否存在 _skillhub_meta.json / _meta.json / _stdd_source.json 平台标记
3. 查 SKILL.md 正文是否含 workbuddy-ai 路径标记

## 证据

- agent_created: true 共 21 个 → 运行/本地产生，可归档
- fstdd 家族无 agent_created：fstdd-field-notes / fstdd-upgrade 含 workbuddy-ai 路径标记（平台产生确证）；fstdd / fstdd-build / fstdd-deliver / fstdd-spec / fstdd-understand 为 no-mark

## 处理（建议）

归档判据：仅 agent_created: true 或经人工确认本地创建者纳入；凡带市场/平台标记或 workbuddy-ai 路径的一律排除。

## 性质

来源识别是归档口径治理的前置；标记缺失时须人工确认，不可臆测。
