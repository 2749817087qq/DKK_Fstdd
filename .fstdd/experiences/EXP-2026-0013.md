## 现象

新写的 `tools/verify_trae_skills.py` 跑一次，用户真实全局注册表
`~/.fstdd/projects.yaml` 就多出一条 `stdd_smoke_<随机串>` 条目，指向随后被
`shutil.rmtree` 删掉的临时目录。实测连续跑校验器 DELTA=2（258 → 260）。

## 根因

`verify_trae_skills.py` 的 CLI 端到端冒烟在 `tempfile.mkdtemp()` 里执行
`fstdd init / new / status`，但只改了 `cwd`、**没有改 `HOME`**；而
`fstdd init` 经 `_register_project()` 写
`Path.home()/".fstdd"/"projects.yaml"`
（`upstream/fstdd/cli/commands/upgrade.py:33`）。于是：

- 临时目录是隔离的，**用户级状态写入面不是隔离的**；
- 冒烟目录随后被清理 → 注册表里留下指向已删除目录的悬空条目；
- 校验器模块 docstring 自述「只读」→ 该自述变成假陈述。

**这是 EXP-20260916-INSTALL-2 的复发**（同一家缺陷：冒烟未隔离 HOME），
当时只在 `verify_workbuddy_skills.py` 侧手工清理过注册表，未落地根治；
本次新增 Trae 侧校验器时照抄了冒烟写法，于是同一缺陷在新脚本上重现。

## 检测信号

跑校验器前后统计注册表中的冒烟条目数，DELTA 必须恒为 0：

```bash
python3 - <<'PY'
from pathlib import Path
p = Path.home()/".fstdd"/"projects.yaml"
print(sum(1 for l in p.read_text().splitlines() if "stdd_smoke_" in l))
PY
```

更稳妥的做法是把「注入一个假 HOME 探针，跑完后断言探针下没有
`.fstdd/projects.yaml`」写成用例（本次已落地 TC-TSV-009）。

## 修复模板

```python
import site
USER_SITE = site.USER_SITE          # 必须在任何 HOME 改写之前取值

env = dict(os.environ)
env["HOME"] = str(tmp / "home")     # 隔离用户级状态写入面
(tmp / "home").mkdir()
if USER_SITE and os.path.isdir(USER_SITE):
    parts = [p for p in env.get("PYTHONPATH", "").split(os.pathsep) if p]
    if USER_SITE not in parts:
        env["PYTHONPATH"] = os.pathsep.join([USER_SITE, *parts])
```

第二个 `PYTHONPATH` 透传不是可选项：`site.USER_BASE` 由 `Path.home()` 推导，
改 `HOME` 会让用户级 site-packages 从 `sys.path` 消失。本机 `markupsafe` 恰好装在
`~/.local/lib/python3.13/site-packages`，不透传就会报「当前解释器缺少依赖
markupsafe」——把「测试隔离问题」伪装成「环境缺依赖」，排查方向被带偏。

## 性质

测试/自检脚本的**状态写入面隔离**缺陷：凡是会写用户级状态的命令
（注册表、缓存、配置），冒烟与集成测试必须同时隔离**文件系统作用域**
（临时目录）与**用户级状态作用域**（`HOME`）。只隔离前者是本缺陷的普遍形态。

## 第二次命中（2026-09-30，occurrences 1 → 2）

同一缺陷面这次复用在**判据层**而不是代码层：TC-NS-011 的初版污染判据写成
「跑校验前后条目数差为 0」+「文件 sha256 前后相同」。实测两者**同时成立而污染确实存在**
—— 等量替换（同名重登记、path 变动）与换行/顺序差异都不改变计数与哈希。
改用 `(name, path)` **命名集合差为空**后复查，发现 4 条当日日期的临时条目，已按名精确删除
（删除前备份 `/tmp/projects.yaml.before-cleanup2.bak`；终态 1373 条、集合唯一数 1373、
2026-09-30 日期条目 0 条）。

⇒ 一般化：**「数量不变」不是「内容不变」的证据**。状态写入面的污染检测必须比对
**被检对象的标识集合**，而不是它的长度或摘要。原「检测信号」小节已按此改写。
