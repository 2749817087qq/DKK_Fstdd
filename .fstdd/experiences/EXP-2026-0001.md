## STDD Guard 阶段门拦截

现象：在 `understand` / `deliver` 等非可编辑阶段调用 Write / Edit 被拒（返回 `Blocked — 未进入可编辑流程`），改动无法落地。

根因：`enforce_stdd=true` 时 Guard 仅放行 `build` / `deliver` 阶段；`gate approve` 只更新 `spec.status`，不会把 `current_phase` 推进到 `build`，因此确认 Gate 后仍写不进去。

检测触发：在非 build/deliver 阶段尝试写文件即被拒；Gate 确认不会自动解锁写权限。

修复模板：先 `stdd phase set <change> build`（→ `current_phase: build`，`build.status: in_progress`）再写；临时绕过可用 Bash heredoc 重定向或 CLI（Guard 不拦截 shell）。
