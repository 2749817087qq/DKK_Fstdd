## 现象

时钟巡检三态判定（SC-024/025/026）要求：可接受（0) / 超限（1) / 无法测量（2)。
Slice 1 初版实现 `err_upper = abs(offset) + min_rtt / 2`。

## 根因

err ≥ |offset| 恒成立 → SC-025 的前提「err ≤ TOLERANCE 且 abs(offset) > TOLERANCE」
是空集 → **「超限」分支是死代码**。spec 要求的退出码 1 永远不会出现。

## 证据（决定性）

TC-CAL-004 用例构造 offset=2.5 > 容差 2.0、rtt=0.2：
- 按错误公式：err = 2.5 + 0.1 = 2.6 > 2.0 → 落入 err 分支
- 按正确公式 err = rtt/2 = 0.1 ≤ 2.0 且 |offset| > 2.0 → 真「超限」
测试断言 exit 1，Slice 1 实现返回 2 —— 红。

反向验证：why.evidence (6) 的实测「RTT ~5.5s → err ≈ 2.7s」正是 5.5/2，
与 offset 无关。

## 一般化

多态契约的验收必须包含**每态可达性用例**。直觉公式 + happy path 测试
= 死代码温床。实测数据是公式语义的最权威判据。
