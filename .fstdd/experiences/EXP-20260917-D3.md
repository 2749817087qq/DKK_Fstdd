## 现象

`./install.sh` 成功后输出：

```
 安装完成
 skill 目录: $HOME/.workbuddy-ai/skills    ← 错误
```

但实际 skill 装在 `$HOME/.workbuddy/skills`（install_workbuddy_skills.py 的默认 OUT）。

## 根因

install.sh 的 echo 使用 `$HOME/.workbuddy-ai/skills` 作为默认值，
而 install_workbuddy_skills.py 已修正为 `<DOMAIN>() / ".workbuddy" / "skills"`。
两处默认值不同步，此问题在 2026-09-16 首次审计时已指出（P2），本次（2026-09-17）仍未修复。

## 修复建议

install.sh 第 101 行的 echo 默认值改为 `$HOME/.workbuddy/skills`，与安装脚本一致。
