（fixture 里真调 `_write_upgrade_notes`）+ 相关测试红。

## 根因

Slice 3 做时间戳统一时，三处改写写成 `_dt.now(_dt.timezone.utc)`。
单测覆盖的两处没暴露（fixture 路径外的 except 吞掉了），
直到全量套件的真实路径测试才炸出 AttributeError。

## 证据（决定性）

```
AttributeError: type object 'datetime.datetime' has no attribute 'timezone'

```
guard.py 两处（196/517）无直接测试，靠修复后人工审查同模式 grep 全仓补抓。

## 一般化

改造类任务的验收标准不是「静态检查过」，而是「每条被改代码路径都有
真实执行记录」。长期零命中的检测逻辑是可疑资产，要用变异测试证伪
「它真的在干活」。
