## 现象

已初始化的项目运行 `fstdd status`：

```
  Guard: ⚠️ 未安装 — 执行 stdd guard init 安装
```

提示里的命令名是 `stdd guard init`，但 CLI 入口已改名为 `fstdd`，
照提示执行会报「command not found: stdd」。

## 根因

上游改名时 status 命令输出文案未全量替换。属非致命问题（Guard 是可选增强），
但会误导首次使用者。

## 修复

实际命令用 fstdd 入口：

```bash
<venv_python> <upstream>/bin/fstdd guard init
```

建议上游在 status 输出与 guard 子命令的提示中全量替换 `stdd` → `fstdd`。
