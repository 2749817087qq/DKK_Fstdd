## 现象

`fstdd init` 输出中：

```
  [FSTDD Guard] PreToolUse hook -> .claude/<DOMAIN>.json
  [FSTDD Guard] PreToolUse hook -> .codebuddy/<DOMAIN>.json
  [STDD Guard] All Edit/Write operations will be checked.    ← 残留
    经验库: ⚠️ 空（手动拉取: stdd experience pull）           ← 残留
```

`fstdd status` 输出中：

```
  Guard: ⚠️ 未安装 — 执行 stdd guard init 安装                 ← 残留
```

## 根因

上游改名时输出文案未全量替换。`[FSTDD Guard]` 已改但紧邻的 `[STDD Guard]` 漏改——
说明替换是逐行手改而非全局 sed，容易遗漏。

## 修复建议

```bash
# 全量扫描残留
grep -rn "stdd " upstream/fstdd/cli/ | grep -v "fstdd"

# 应返回空；非空则逐一替换为 fstdd
```
