## 现象

在 Windows Git Bash 沙箱中，cat > /tmp/x.py 写入与随后 python /tmp/x.py 读取路径错位，python 报 can't open file '<PATH>'。

## 复现

沙箱内使用 /tmp 作为临时脚本路径：写与读落在不同可见路径。

## 证据

/tmp 被解析为 <PATH> Heredoc 实际写入位置不一致。

## 处理（建议）

临时脚本一律写入项目目录绝对路径（如项目根目录下的临时文件），并以绝对路径运行，执行后清理。

## 性质

环境坑，影响所有临时脚本执行；已固化为执行惯例。
