## 回传机制的两个隐性事实（重要）

1. **publish 提交的是导出目录 `experiences/` 全量**，不是本次导出集合。
   所以手工丢进 `experiences/` 的 `.md` 也能回传 —— 这是报告能进通道的真正原因，
   属未文档化的隐式行为。
2. `collect_local()` 只读源目录 `.fstdd/experiences/`（15 条）→ 决定 README 索引；
   publish 扫 `experiences/`（27 个）→ 实际提交。**两者口径不一致**（P10），
   且每次全量提交会重复累加服务端 `received`（观测 87→181 一次涨 94）。
   建议：客户端按 ID 做增量，或服务端按 experience_id 去重。
