# FSTDD-Quant · 量化规驱

> **这不是把 Spec 模板贴进 FSTDD。**
> 网上的量化 Spec 模板给的是「该检查什么」——一份清单；
> FSTDD 给的是「怎么保证它真的被执行」——流程引擎 + 强制门禁 + 自动归档。
> 本 skill 把量化策略研发的领域知识**逐条翻译**成 FSTDD 流程里的**强制规格项、阻断门禁与验收项**：
> 清单上的每一条，要么在 SPEC 阶段变成可测试的规格，要么在 BUILD 阶段变成阻断项，要么在 DELIVER 阶段变成打勾项。
> 落在流程之外的知识 = 不会被执行的知识。

---

## 0. 职责边界（先分清楚，别串台）

| 场景 | 用谁 |
|------|------|
| 量化策略研发（因子挖掘/组合构建/回测仿真/实盘评估） | **本 skill（fstdd-quant）** |
| 金融系统研发（支付/交易/风控/合规） | `fstdd-fin` |
| 看行情、分析个股、估值建模、给投资建议 | `wb-finance-skill`（腾讯 WorkBuddy 产品自带，非 FSTDD 组件） |
| 通用软件研发（非量化、非金融） | `fstdd` 通用系列 |
| 只需量化 Spec 模板、不走完整 FSTDD 流程 | 直接用网上的 Spec 模板即可 |

**协作契约**：

- **领域知识已内化在本 skill**，不依赖任何外部 skill，可独立分发与安装。
- `fstdd-fin` 的七条红线中，**红线1（Decimal）、红线5（降级不静默）、红线7（无硬编码）** 在量化场景下同样适用，本 skill 在第1节显式继承。
- 需要市场 / 财务数据时，按 `wb-finance-skill` 的规范取数（优先 `agentic_search`，禁止凭记忆输出数值）。

## 1. 量化策略研发红线（一票否决，贯穿全流程）

> 继承 fstdd-fin 红线1/5/7，新增量化专属红线4条，共7条。

| # | 红线 | 违反后果 | 来源 |
|---|------|---------|------|
| 1 | **PIT 原则**：所有数据、财务、行业、指数成分必须使用当时可得信息，禁止未来函数 | Gate 不通过 | quant 专属 |
| 2 | **成本优先**：IC 高不代表可交易，扣费后无 alpha 的因子直接淘汰；成本敏感性必须覆盖万1/万3/万5/千1 | Gate 不通过 | quant 专属 |
| 3 | **样本外优先**：最终结论必须经过时间样本外和股票池样本外验证，禁止用样本外反复调参 | Gate 不通过 | quant 专属 |
| 4 | **可复现**：数据版本、代码版本、因子版本、实验参数必须记录，任意一次实验可完整重放 | Gate 不通过 | quant 专属 |
| 5 | **金额用 Decimal**：收益率、净值、成本计算禁止 float | Gate 不通过 | fstdd-fin 继承 |
| 6 | **降级不静默**：数据缺失/接口不可用时必须显式标记+告警，禁止用脏数据/过期数据静默出结果 | Gate 不通过 | fstdd-fin 继承 |
| 7 | **无硬编码凭据与常量**：API密钥/数据库连接/费率/阈值一律走配置，不进代码与版本库 | 安全验收不通过 | fstdd-fin 继承 |

> 红线2「成本优先」是量化策略最隐蔽的杀手：回测夏普3.0的策略，加上真实成本后可能变成负alpha。
> **任何因子进入组合前，必须通过成本敏感性阻断门禁。**

## 2. 四阶段 · 量化增强

### P1 UNDERSTAND — 需求理解（量化版必答项）

在标准 proposal 之外，**逐项明确**才允许进入 P2（缺一项 = Gate 1 不通过）：

| 必答项 | 说明 |
|--------|------|
| **市场/品种** | A股/港股/美股/期货/期权？哪个指数/成分股？ |
| **数据频率** | Level-2快照/逐笔/分钟线/日频？多频率混合？ |
| **因子频率与持有期** | 因子计算频率（1s/1min/日频）？预测收益周期（60s/5min/1d）？ |
| **研究样本** | 起止日期？训练/验证/测试切分方案？ |
| **目标** | 挖掘Alpha因子？构建组合？评估已有策略？实盘可行性？ |
| **约束** | 换手上限？成本假设？容量要求？延迟容忍？中性化要求？ |
| **降级策略** | 数据缺失/接口超时/行情中断时怎么办？（**必须逐条填，不许留白**） |

### P2 SPEC — 规格设计（量化版核心增值）

除常规 design.md + specs + test-plan.md，**强制新增四份契约**：

#### 2.1 数据契约（Data Contract）

每个数据源一行：数据源名称 / 核心字段 / 频率 / 质量门禁阈值 / PIT确认 / 版本号 / **降级行为**。

**质量门禁阈值未填 = 规格不完整**，禁止进入 P3。

必含字段：
- 时间戳单调性、去重、时区统一
- 价格>0、买卖价差≥0、量额≥0
- 停牌/涨跌停/ST/新股标记完整性
- 复权因子一致性
- 缺失率/异常率/覆盖率阈值
- 财务/行业/指数成分的 PIT 确认

#### 2.2 因子定义契约（Factor Contract）

每个因子一张定义卡：

| 项目 | 内容 |
|------|------|
| 因子名 | `{类别}_{窗口}_{变换}_{版本}` |
| 类别 | 微结构/量价/动量/波动/位置/基本面 |
| 公式 | 明确数学表达式 |
| 输入字段 | 字段名、频率、窗口 |
| Universe | 股票池、剔除规则 |
| 预处理顺序 | 去极值(MAD) → 缺失处理 → 标准化(Z/Rank) → 中性化 → 截断 |
| 输出表 | factor_value 表结构 |
| 版本 | 因子版本号 |

**命名不规范或预处理顺序未定义 = 规格不完整。**

#### 2.3 验证流程契约（Validation Protocol）

**11步验证流程，步骤1和步骤4为阻断门禁**：

| 优先级 | 步骤 | 内容 | 门禁 |
|--------|------|------|------|
| 第一 | 1. 因子相关性分析 | 60日截面相关矩阵，Pearson+Spearman | **【阻断】** \|corr\|>0.9 视为重复 |
| 第一 | 2. 分组单调性 | 5-10组，单调性、极端组依赖 | 参考 |
| 第一 | 3. 市值/行业中性化IC | 残差重算IC，下降过大=风格暴露 | 参考 |
| 第二 | 4. 换手率与成本敏感性 | 万1/万3/万5/千1，扣费后净IC/净ICIR | **【阻断】** 净IC≤0 淘汰 |
| 第二 | 5. 容量分析 | ADV约束、资金容量上限 | 参考 |
| 第二 | 6. 执行延迟影响 | 1s/5s/10s/30s 重算IC | 参考 |
| 第三 | 7. 多因子合成 | 低相关等权/IC加权/最大化ICIR | 参考 |
| 第三 | 8. 分时段稳健性 | 上涨/下跌/震荡、高/低波动 | 参考 |
| 第三 | 9. 极端行情压力测试 | 大涨/大跌/流动性危机日 | 参考 |
| 第四 | 10. 时间样本外 | 向前扩展，最近30天完全保留 | 参考 |
| 第四 | 11. 股票池样本外 | 换池/Bootstrap | 参考 |

**Gate 2**：四份契约经用户确认后锁定。步骤1和步骤4的阻断标准必须写死具体数值。

#### 2.4 口径定义表（Glossary）

把所有歧义写死：

- IC / RankIC / ICIR 的计算公式
- 换手率：单边 `0.5 × Σ|w_t - w_{t-1}|`
- 执行延迟 D 的具体取值
- 可成交价：VWAP / 对手价 / 开盘价（不用理想中间价）
- 成本模型：佣金 + 印花税 + 过户费 + 滑点 + 冲击成本
- 标签公式：`r_{t,H} = exec_price_{t+D+H} / exec_price_{t+D} - 1`
- 频率约定：禁止混频比较

### P3 BUILD — 实现（量化版硬规则）

以下为**强制项**，不是建议：

**数据与因子**
1. 数据质量门禁不通过，不得进入因子计算
2. 因子预处理顺序严格按契约执行，不得跳步
3. 标签构建必须可交易、无未来函数
4. 每个因子必须有定义卡，命名符合规范

**验证与门禁**
5. 11步验证严格按优先级顺序执行，不得跳步
6. 步骤1（相关性）和步骤4（成本敏感性）为阻断项，不通过不得进入组合构建
7. 高相关因子必须合并或正交化，保留经济含义强、换手低、容量大者
8. 扣费后净IC ≤ 0 的因子直接淘汰，不论原始IC多高

**回测与仿真**
9. 事件驱动回测，禁止收盘价未来函数
10. 涨跌停不能成交，停牌剔除
11. 信号延迟 D 后成交，使用可成交价
12. 成本模型完整（佣金+税+滑点+冲击），turnover 公式正确

**工程与可复现**
13. 每次实验记录：experiment_id / data_version / factor_version / universe / horizon / delay / cost / metrics / conclusion
14. 数据版本、代码版本、因子版本写入每个产出物
15. 目录结构标准化：configs / data / factors / labels / evaluation / portfolio / backtest / experiments / reports / tests

### P4 DELIVER — 交付（验收清单）

交付前逐项打勾，缺一不可：

- [ ] 数据质量门禁通过，PIT 确认无未来函数
- [ ] 因子定义卡完整，命名规范，预处理顺序正确
- [ ] 步骤1 因子相关性分析通过，高相关已处理
- [ ] 步骤4 成本敏感性通过，扣费后净IC > 0
- [ ] 分组单调性检验通过
- [ ] 中性化IC通过，风格暴露可控
- [ ] 执行延迟衰减可接受
- [ ] 容量满足目标资金
- [ ] 分时段稳健性同号比例 ≥ 60%
- [ ] 极端行情压力测试无爆雷
- [ ] 时间样本外 IC 同号且显著
- [ ] 股票池样本外 IC 同号且显著
- [ ] 回测事件驱动，涨跌停/停牌处理正确
- [ ] 成本模型完整，扣费净值已计算
- [ ] 实验记录完整，任意一次实验可重放
- [ ] 无硬编码凭据与常量
- [ ] 文档完备（Spec、因子定义卡、验证报告、回测报告、实验记录）

## 3. 量化策略特有测试维度（测试方案必含）

在常规单测之外，**必须**覆盖：

| 维度 | 测什么 |
|------|--------|
| **PIT/未来函数** | 财务数据时点、滚动窗口边界、标签时间戳对齐 |
| **因子相关性** | 截面相关矩阵、聚类树、VIF、高相关合并/正交化 |
| **成本敏感性** | 万1/万3/万5/千1 四档扣费后净IC/净ICIR |
| **执行延迟** | 1s/5s/10s/30s 延迟后IC衰减曲线 |
| **容量** | 按成交额分位分组、ADV约束、资金容量上限 |
| **分组单调性** | 5-10组收益单调、极端组依赖、剔除top/bottom 1%后IC |
| **中性化** | 市值/行业中性化后IC变化、风格暴露度 |
| **分时段稳健** | 上涨/下跌/震荡、高/低波动、不同月份同号比例 |
| **极端行情** | 大涨/大跌/流动性危机日IC、回撤、单日巨亏 |
| **样本外** | 时间样本外 + 股票池样本外，禁止反复调参 |
| **数据质量** | 缺失率、异常率、覆盖率、时间戳单调、去重 |
| **可复现** | 相同输入 → 相同输出，实验ID可追溯 |

## 4. 失败模式（量化策略特有）

| 模式 | 表现 | 拦截点 |
|------|------|--------|
| **未来函数** | 用了当时不可得的数据，回测虚高 | PIT检查 + 时间戳对齐测试 |
| **虚假Alpha** | 原始IC高但扣费后为负 | 成本敏感性【阻断门禁】 |
| **重复因子** | 多个因子本质是同一信号 | 相关性分析【阻断门禁】 |
| **风格暴露** | Alpha来自小市值/行业而非因子本身 | 中性化IC检验 |
| **过拟合** | 训练集IC高、样本外IC反转 | 时间+股票池双样本外 |
| **流动性幻觉** | 回测假设无限流动性，实盘无法成交 | 容量分析 + ADV约束 |
| **延迟失效** | 信号生成到成交延迟后IC归零 | 执行延迟衰减测试 |
| **极端日爆雷** | 正常日稳定，危机日巨亏 | 极端行情压力测试 |
| **数据污染** | 除权跳空、停牌未剔除、ST未标记 | 数据质量门禁 |
| **不可复现** | 相同代码跑出不同结果 | 版本锁定 + 实验记录 |

## 5. 子 Spec 模板（P3 BUILD 切片参考）

> 以下四个子 Spec 对应 P3 的四个垂直切片。每个子 Spec 必须挂接总 Spec，不得绕过门禁。

### 5.1 数据分析子 Spec

**目标**：确认数据可用性、覆盖率、质量，为因子构建提供可信输入。

必含：数据源清单、核心字段表、质量门禁阈值、PIT确认、数据版本号、缺失/异常清单、降级行为。

**门禁**：关键字段覆盖率 ≥ 99%，异常率 ≤ 0.1%，PIT 通过。不通过不得进入因子构建。

### 5.2 因子构建及分析子 Spec

**目标**：构建可复现因子，完成11步验证，筛出可进入组合的因子。

必含：因子定义卡、命名规范、预处理顺序、标签构建、11步验证结果、相关矩阵、分组收益、中性化IC、成本敏感性表、延迟衰减曲线。

**门禁**：步骤1和步骤4通过。扣费后净IC > 0。不通过不得进入组合构建。

### 5.3 模型训练子 Spec

**目标**：用通过门禁的因子训练预测模型，输出可交易信号。

必含：样本切分方案（时间序列，禁止随机打乱）、特征处理、模型选择、超参搜索、正则化/早停、特征重要性、过拟合检测（PSI/因子漂移）。

**门禁**：测试集扣费后净IC > 0，净ICIR > 阈值，样本外同号，无单一因子贡献 > 50%。

### 5.4 回测子 Spec

**目标**：在贴近实盘约束下评估策略净值、风险、容量与可交易性。

必含：事件驱动框架、涨跌停/停牌处理、延迟成交、可成交价、成本模型、换手约束、容量曲线、归因分析、稳健性/压力测试、样本外。

**门禁**：扣费后净IC > 0，容量满足目标资金，延迟30s后仍有效，极端日无爆雷。
