## 现象

导出经验/文档并脱敏后，正文变成：

```
**现象**：GREEN 首轮报 `索引 diff 1 个文件：<DOMAIN>`。     ← 原文是 README.md
**处理**：引入 `ALLOWED_DIFF = {"<DOMAIN>"}`               ← 原文是 {"README.md"}
```

内容完全失去意义。

## 根因

域名正则 `(?:[a-z0-9-]+\.)+[a-z]{2,}` 对 `README.md` 是完美匹配：
`README` 匹配 `[a-z0-9-]+`，`.md` 匹配 `\.[a-z]{2,}`。

**问题不在于正则写错，而在于把"形似"当成了"实质"。**

## 处理

```python
FILE_EXTS = {"md","py","txt","json","yaml","yml","sh","ps1","log","lock", ...}

def _dom(m):
    raw = <DOMAIN>(0)
    if <DOMAIN>(".", 1)[-1].lower() in FILE_EXTS:
        return raw          # 文件名，不动
    if <DOMAIN>() in PUBLIC_DOMAINS:
        return raw          # 公共域名，不动
    return "<DOMAIN>"
```

## 关键教训

**脱敏规则必须拿真实数据跑一遍，看误伤，不能只看"命中了几条"。**

第一轮我看到输出「脱敏命中: 域名」时以为是对的——实际上那些"命中"全是误伤
（把 README.md 当域名了），真正的敏感信息（绝对路径、IP）反倒因为样本里没出现而没被检验到。

「命中数」是过程指标，不是正确性指标。
