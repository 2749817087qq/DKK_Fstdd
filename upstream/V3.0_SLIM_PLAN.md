# STDD V3.0 瘦身 + Batch Pipeline 计划

> 日期: 2026-07-09 | 状态: **已在 V3.0.5 内核落地**（2026-09-29 逐项核对，见文末「落地核对」）
> 版本: V3.0.x

---

## 一、瘦身三项

### 1. 合并 SLICE-BUILD-VERIFY → BUILD (6 Phase → 4 Phase)
P3 SLICE/P4 BUILD/P5 VERIFY 合并为 P3 BUILD
Phase 推进从 6 次 CLI 变为 4 次

### 2. YAML 优先，MD 仅 Gate 时自动生成
AI 只写 YAML。canon generate 在 Gate 时自动翻译 YAML→MD 给人看

### 3. CLI 按场景分组
[流程][管控][工具][维护][批量] 五个分组

---

## 二、Batch Pipeline

Batch 支持 proposal.md + design.md → 批级别 Gate 1+2
子 change 继承 scope → 各自 BUILD(长程自动) → 批量 DELIVER

无 proposal/design → 原 Batch 模式（完全兼容）

---

## 三、实施顺序

Change 1: 合并 Phase (6→4) + Skill 合并
Change 2: YAML 优先 + Gate 自动 MD
Change 3: Batch Pipeline + CLI 分组

全部 V3.0.x 内发布。
